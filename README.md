# Restaurant Cafe

A PHP-based restaurant cafe management system built for managing products, orders, reservations, users, and related cafe operations.

## Features

- User registration and login
- Product and menu management
- Order management
- Reservation management
- Admin dashboard
- Analytics
- Password reset
- Google authentication
- Email notifications

## Technologies

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- PHPMailer
- Composer
- XAMPP

## Local Setup

1. Clone the repository.
2. Place the project inside your XAMPP `htdocs` folder.
3. Install Composer dependencies:
   ```bash
   composer install

   This project is intended for local development and educational/project use.
